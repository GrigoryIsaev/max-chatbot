# MAX-бот домашних заданий по английскому языку

Бот работает через Long Polling, хранит состояние в SQLite и обновляет одну Google-таблицу через Google Apps Script. Для каждого класса создаётся **один лист** с ФИО, актуальностью состава и отдельным столбцом на каждое задание.

## Файлы проекта

- `bot.py` — MAX Long Polling, команды преподавателя, приём фото/видео, напоминания и уведомления.
- `google_sheets.py` — вызовы Google Apps Script.
- `apps_script.gs` — код для редактора Apps Script.
- `students.csv` — текущий список учеников.
- `.env.example` — пример конфигурации.

## 1. Обновить Google Apps Script

1. Открой существующую Google Таблицу.
2. Перейди в **Расширения → Apps Script**.
3. Полностью замени старый код содержимым файла `apps_script.gs`.
4. В начале кода заполни `SPREADSHEET_ID`: это часть ссылки между `/d/` и `/edit`.
5. В `API_KEY` вставь секретный ключ. Он должен совпадать с `GOOGLE_SCRIPT_KEY` в `.env`.
6. Сохрани код и выбери **Развернуть → Управление развертываниями**.
7. Открой текущее развертывание, нажми редактирование и выбери новую версию кода. Если редактирование недоступно — создай новое веб-приложение.
8. Выполнение — от имени владельца таблицы. Используй доступ, разрешённый настройками твоего Google-аккаунта. Скопируй URL, заканчивающийся на `/exec`, в `.env`.

Существующие листы старого формата не преобразуются автоматически. Новый код будет создавать/использовать листы с именами классов и скрытый служебный лист `_Задания`. Не удаляй старые листы, пока не убедишься, что нужная история сохранена.

## 2. Настроить Python

1. Распакуй архив в папку проекта.
2. Скопируй `.env.example` в `.env`, если `.env` ещё нет. Не перезаписывай существующий настроенный `.env`.
3. Заполни значения:

```env
MAX_BOT_TOKEN=ТОКЕН_БОТА_MAX
TEACHER_IDS=394626386
GOOGLE_SCRIPT_URL=https://script.google.com/macros/s/ТВОЙ_ID/exec
GOOGLE_SCRIPT_KEY=ТОТ_ЖЕ_СЕКРЕТ_ЧТО_В_APPS_SCRIPT
TIMEZONE=Europe/Moscow
MAX_API_BASE=https://platform-api2.max.ru
POLL_TIMEOUT=30
POLL_PAUSE=1.0
DB_PATH=bot.sqlite3
STUDENTS_CSV=students.csv
LOG_LEVEL=INFO
```

`TEACHER_IDS` — числовые ID преподавателей MAX через запятую. Чтобы бот мог отправлять личные уведомления, преподавателю нужно открыть диалог с ботом и отправить `/start`.

Установи зависимости в PowerShell из папки проекта:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python bot.py
```

Если виртуальное окружение уже создано, повторно создавать его не нужно.

## 3. Формат `students.csv`

Файл должен лежать рядом с `bot.py` и иметь заголовки `class,full_name`:

```csv
class,full_name
7,Иванов Иван Иванович
7,Петров Пётр Петрович
8,Кузнецов Алексей Иванович
```

Сохраняй файл в UTF-8. После изменения CSV бот перечитывает состав примерно каждые 5 минут; можно также вызвать `/sync` в нужной группе. Новые ученики добавляются в лист. Выбывшие не удаляются физически, а помечаются `Выбыл`, чтобы сохранить историю прошлых заданий. Для новых учеников старые столбцы заданий остаются пустыми.

## 4. Команды в групповом чате

Сначала преподаватель привязывает чат к классу из CSV:

- `/bind 7` — привязать этот чат к классу 7 и синхронизировать состав.
- `/unbind` — снять привязку текущего чата.
- `/new Название|Условие|ГГГГ-ММ-ДД ЧЧ:ММ` — создать задание в текущем чате.
- `/list` — показать активные задания этой группы.
- `/close 12` — закрыть задание №12 в текущей группе.
- `/sync` — немедленно обновить состав группы из CSV.
- `/help` — помощь.

Пример:

```text
/new Workbook p. 15|Выполнить упражнения 1–5|2026-11-02 18:00
```

Номер задания назначается автоматически. После создания бот публикует условие и срок сдачи в том же групповом чате. Команды управления работают только для ID преподавателей, указанных в `TEACHER_IDS`.

## 5. Как сдавать работу

Ученик отправляет фото или видео в группу с подписью:

```text
ID задания: 12
ФИО: Иванов Иван Иванович
```

Также поддерживается короткий формат `12, Иванов Иван Иванович`. Класс определяется по привязке группового чата. При первой зарегистрированной сдаче бот обновляет соответствующую ячейку в столбце задания и уведомляет преподавателей.

## 6. Структура Google-таблицы

Для каждого класса создаётся один лист с колонками:

- `ФИО ученика`;
- `Состав` (`В списке` / `Выбыл`);
- `Заметки`;
- отдельная колонка `Задание #N — название — срок ...` для каждого задания.

В ячейках задания хранится статус сдачи и время. Закрытие задания помечает заголовок столбца как `[ЗАКРЫТО]` и закрывает его в локальной базе бота. Служебный лист `_Задания` скрыт и хранит метаданные заданий.

## Важно

- Не удаляй `bot.sqlite3`: там находятся номера заданий, привязки чатов и история сдач.
- Не отправляй кому-либо `.env`, токен MAX или секрет Apps Script.
- После замены Apps Script обязательно обнови развертывание на новую версию.
- После первого запуска проверь `/bind`, создание тестового задания, сдачу с фото и `/close` в тестовой группе.
